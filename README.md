# FeaturedStore 精选商城项目

> 前后端分离商城系统

## 项目模块
- 🖥️ Featured_Store_Server：SpringBoot 后端服务
- 🎨 Featured_Store_Web：用户端前端页面
- 🔧 Featured_Store_Admin：管理后台前端
- 🗄️ Featured_Store_Database：数据库SQL脚本

## 技术栈
后端：SpringBoot + Maven + MyBatis
前端：
数据库：MySQL

## 启动说明
1. 导入 `Featured_Store_Database` 下的sql文件，初始化数据库
2. 进入 Featured_Store_Server 配置yml数据库连接
3. 启动SpringBoot后端
4. 启动对应前端项目
